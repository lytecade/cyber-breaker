# CyberBreaker

A cyberpunk-themed brick-breaker arcade game built with vanilla HTML5 Canvas and JavaScript.

## Gameplay

- **Launch the ball** by clicking, tapping, or pressing Enter.
- **Move the paddle** by dragging (mouse/touch) or using the left/right arrow keys.
- Break all blocks to advance to the next wave.
- You have **5 lives** — don't let the ball drop!
- Score increases with each block destroyed and each wave cleared.
- A **high score** is displayed when all lives are lost.

## Controls

| Action | Keyboard | Touch / Mouse |
|---|---|---|
| Move paddle | ← / → arrows | Drag on screen |
| Launch ball | Enter | Click / Tap |
| Start game | Any key | Click / Tap |

## Features

- Square game canvas that scales to fill the browser window
- Cyberpunk aesthetic using the Arne16 color palette
- Progressive wave system with increasing difficulty
- Mobile-friendly touch controls
- No external dependencies — pure HTML5 + JS

## Running

Open `index.html` in any modern browser. No server required.
